# Descargas

- **JBPersonal_Setup.exe**: instalador de JB-Personal 1.1.1 para Windows 10+ (Siguiente → Instalar → Finalizar).
- **Manual_JB-Personal.pdf / .docx**: manual de implementación, instalación, activación y pruebas.

El instalador no está firmado digitalmente: si Windows muestra «protegió su PC», pulse *Más información → Ejecutar de todas formas*.
SHA-256 del instalador: ver `JBPersonal_Setup.exe.sha256`.
